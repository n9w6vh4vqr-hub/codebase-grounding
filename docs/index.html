codebase-grounding construye GROUNDING.md: un artefacto de contexto curado por repositorio, para que Claude entienda tu arquitectura y tus restricciones reales antes de revisar código.

codebase-grounding es una skill open source para Claude Code que genera GROUNDING.md a partir de tu propio repositorio. Está pensada para equipos de desarrollo que usan Claude Code y quieren revisiones de código ancladas a su arquitectura real, no a patrones genéricos. Se instala en minutos con git clone, es gratis bajo GPL v3, y existe una licencia comercial para quien no puede asumir el copyleft.

Cómo funciona

Cuatro pasos, sin diagramas complicados.

01

SCOPE

Curas explícitamente qué archivos entran al contexto, cada uno con una justificación de una frase. Nunca escanea todo el repo.

02

ASSEMBLE

Construye GROUNDING.md distinguiendo el estado actual del código del estado deseado, y escanea secretos antes de escribir nada.

03

APPLY

Claude usa ese contexto para revisar o sugerir código anclado a tu codebase, no a lo genérico.

04

PERSIST

Guarda el hash SHA-256 del conjunto de archivos; la próxima sesión verifica si el repo cambió antes de reutilizarlo.

Instalación

Se instala copiando la carpeta, sin npm ni pip.

$ git clone https://github.com/n9w6vh4vqr-hub/codebase-grounding.git
$ cp -r codebase-grounding ~/.claude/skills/codebase-grounding
# requiere Python 3.9+, sin dependencias

FAQ

Preguntas frecuentes

¿Es gratis?

Sí. Es gratis y de código abierto bajo GPL v3 para desarrolladores independientes, startups, proyectos open source y uso educativo.

¿Qué pasa si lo modifico?

Puedes modificar y distribuir libremente. Si compartes públicamente una versión modificada, debe ir bajo GPL v3, y debes dar crédito. Si esa obligación no te sirve, la licencia comercial la elimina.

¿Funciona con Claude Code?

Sí, es una skill de Claude Code / Claude, no un paquete de npm ni pip. Se invoca en lenguaje natural dentro de la sesión; el CLI incluido solo requiere Python 3.9+, sin dependencias.

¿Puedo usarlo en mi SaaS o en servicios a clientes?

Bajo GPL v3, sí, aceptando el copyleft. Si la usas como parte de un servicio de pago a clientes o necesitas mantener modificaciones privadas, la licencia comercial es la vía.

¿Qué es exactamente GROUNDING.md?

Un artefacto de contexto curado que vive en la raíz del repositorio que describe: arquitectura real, patrones y restricciones, con lista blanca de archivos y hash de vigencia. Nunca transfiere contexto entre proyectos.

¿Qué pasa si el repo cambia después de generar el contexto?

Cada GROUNDING.md guarda el hash del conjunto de archivos incluidos. Al reutilizarlo, se recalcula y avisa si el repo cambió — sin aceptar a ciegas un contexto desactualizado.
