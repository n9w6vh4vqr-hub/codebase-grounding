How it works

Four steps, no crowded diagrams.

01

SCOPE

You explicitly curate which files enter the context, each with a one-line justification. It never scans the whole repo.

02

ASSEMBLE

Builds GROUNDING.md distinguishing the current state of the code from the desired state, scanning for secrets before writing anything.

03

APPLY

Claude uses that context to review or suggest code grounded in your codebase, not generic patterns.

04

PERSIST

Stores a SHA-256 hash of the file set; the next session verifies whether the repo changed before reusing it.

Honest scope

It does not produce regulatory compliance evidence or defensible traceability for a regulator — that comes from your git history, not this skill. Treat it as a precision, time-saving tool, not a compliance control.

FAQ

Frequently asked questions

Is it free?

Yes. It is free and open source under GPL v3 for independent developers, startups, open source projects and educational use.

What happens if I modify it?

You can modify and distribute freely. A publicly shared modified version must stay under GPL v3, and you must give credit. If that does not work for you, the commercial license removes it.

Does it work with Claude Code?

Yes, it is a Claude Code / Claude skill, not an npm or pip package. It is invoked in natural language inside a session; the included CLI only needs Python 3.9+, no dependencies.

Can I use it in my SaaS or client services?

Under GPL v3, yes, accepting the copyleft terms. If you use it as part of a paid service to clients or need to keep private modifications, the commercial license is the path.

What exactly is GROUNDING.md?

A curated context artifact that lives at the root of the repository it describes: real architecture, patterns and constraints, with a file whitelist and a staleness hash. It never carries context between projects.

What happens if the repo changes after the context was generated?

Every GROUNDING.md stores a hash of the included file set. On reuse, it is recomputed and flags if the repo changed — instead of blindly accepting a stale context.
